# COVID-19 Global Data Analysis

## Overview

This project analyses global COVID-19 data using Python and Pandas to identify patterns in confirmed cases, deaths, recoveries, active cases and recent case growth.

The project focuses on comparing countries and WHO regions using both absolute and relative measures.

## Objectives

- Analyse confirmed COVID-19 cases across countries and regions
- Identify countries with high numbers of deaths and active cases
- Analyse recovery and mortality rates
- Examine one-week case growth
- Investigate relationships between confirmed cases, deaths, recoveries and active cases
- Translate analytical findings into practical recommendations

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Analysis

The project includes:

- Data inspection and cleaning
- Regional analysis
- Top-country analysis
- Recovery-rate analysis
- Mortality analysis
- Active-case analysis
- One-week growth analysis
- Correlation analysis
- Data visualization
- Limitations and recommendations

## Key Findings

1. The Americas had the highest total confirmed-case burden in the dataset.
2. Confirmed cases showed a very strong positive correlation with deaths (approximately r = 0.93).
3. India recorded a 28.11% one-week increase among the top 10 countries by confirmed cases.
4. Serbia had a higher active-case percentage than the US, while the US had a much larger absolute number of active cases.
5. Among countries with at least 10,000 confirmed cases, the UK had the highest reported deaths-per-100-cases value at 15.19%.
6. Absolute counts and percentage-based metrics provide different perspectives and should be interpreted together.

## Limitations

- Confirmed cases do not necessarily represent all actual infections.
- Testing and reporting practices varied between countries.
- Correlation does not establish causation.
- Important contextual variables such as population size, healthcare capacity and testing rates are not included.
- The dataset represents a particular point in time.

## Conclusion

This analysis demonstrates that COVID-19 burden varied considerably across countries and regions. It also demonstrates the importance of distinguishing between absolute measures and relative measures when interpreting data. While the analysis provides useful evidence for decision-making, additional contextual data would be required to fully understand the factors behind differences in mortality, transmission and healthcare burden.
